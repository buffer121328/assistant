# Progress Report

## 适用场景

仅在用户需要日报、周报、项目进展、复盘或状态汇报时使用。

## 所需事实

确认汇报周期、目标或范围、已完成工作、可验证数据、风险、阻塞项、下阶段计划和需要支持的事项。无依据的数据、完成率或风险等级必须标为待确认。

## 输出结构

1. 一句话摘要；2. 本期进展与成果；3. 数据或证据；4. 风险、阻塞与影响；5. 下期计划；6. 需要决策或支持。需要正式留档时可生成 Word；需要字段化跟踪时可生成基础 Excel 表。

## 渐进披露

首屏只给总体状态、最重要成果、最高影响风险和下一步；随后按需展开证据、完整事项和历史对比。没有可靠基线时不生成完成百分比。

## 最终检查

把事实、判断和待办分开；风险必须说明影响与建议动作；避免用模糊的“已推进”“持续跟进”替代可审阅内容。
