# Project Progress Notification

## 适用场景

仅在技术团队需要起草项目进度、里程碑、上线、延期、风险或维护通知时使用。

## 所需事实

确认受众、项目和里程碑、当前状态、已发生变化、业务/技术影响、风险、所需行动、负责人、截止时间和下一更新时间。缺失项标为“待确认”。

## 输出结构

提供标题、状态一句话、变化与影响、风险/阻塞、接收方需要采取的行动、负责人/截止时间、下一检查点和联系渠道。

## 渐进披露

先给可审阅的短通知和明确行动请求；详细时间线、技术原因、缓解措施和 FAQ 仅在受众需要时展开。

## 最终检查

区分计划、已执行和已验证状态；延期说明包含影响和下一更新时间；只生成草稿，不声称已经发送、发布或通知任何人。
