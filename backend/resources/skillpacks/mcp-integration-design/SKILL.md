# MCP Integration Design

## 适用场景

仅在 AI 部设计 MCP 或其他 Connector 候选、工具映射和治理边界时使用。输出是设计草案，不建立真实连接或索取凭证。

## 所需事实

确认目标系统、业务动作、工具清单、输入输出 schema、认证方式引用、数据分类、组织范围、网络边界、风险等级、幂等性、超时、脱敏、审计和撤销方式。真实密钥不得进入材料；缺失项标为“待确认”。

## 输出结构

1. 集成目标与非目标；2. Connector 定义；3. 外部工具到内部稳定键映射；4. 参数与结果约束；5. 凭证引用和数据范围；6. 风险/审批矩阵；7. 测试、灰度和回滚；8. 待确认事项。

## 渐进披露

先给集成价值、涉及系统、最高风险和审批结论；评审需要时再展开 schema、工具逐项风险、错误脱敏和运维细节。

## 最终检查

不得输出真实凭证或私有地址；原始 MCP 工具名不能直接成为可执行权限；候选不代表已安装、已连接或已启用，启用必须“待 AI 部负责人审批”。
